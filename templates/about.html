APEX Simulator — Core Algorithm
Block Bootstrap with CAPE-Adjusted Drift
Step 1 — CAPE-adjusted expected return. Forward return is derived from the current Shiller CAPE ratio via an empirical lookup table calibrated to Campbell & Shiller (1988) and Asness (2012) research. Earnings yield (1/CAPE) is the strongest single predictor of 10-year real returns in the academic literature. At CAPE 32, implied real return is approximately 3–4% annually. At CAPE 15, approximately 10%.
Step 2 — Block resampling. Each simulated path draws consecutive blocks of actual historical S&P 500 annual returns (1928–2024, 97 observations) with replacement. Default block size is 4 years, following Politis & Romano (1994) stationary block bootstrap. This preserves serial correlation — bear markets and crash sequences arrive as intact units, not isolated random draws.
Step 3 — Drift correction. Each resampled return is scaled by the ratio of CAPE-implied return to historical mean return, shifting the distribution centre while preserving its shape. Fat tails (1931: −43%, 2008: −38%) remain in the resampled pool and appear naturally. No distributional assumption is imposed.
Why this is better than Monte Carlo. Monte Carlo assumes returns are log-normally distributed and independently drawn each year. Real returns have fat tails (extreme events more frequent than log-normal predicts) and serial correlation (bad years cluster). Block bootstrap captures both without parametric assumptions. The CAPE adjustment grounds return expectations in current valuations rather than the historical average, which at elevated valuations has systematically overstated subsequent returns.
Index Recommender — Scoring Model
5 weighted dimensions: Valuation 30% · Volatility fit 20% · Diversification 20% · Tax wrapper 15% · Factor quality 15%. Weights reflect the relative importance of each factor for a long-term passive investor. Valuation dominates because the entry CAPE is the strongest predictor of decade returns.
Valuation score. CAPE-implied real return normalised between the worst (S&P 500 at current levels, ~2.5%) and best (MSCI EM ex-China, ~10%) available in the tracked universe. Higher implied return → higher score.
Volatility fit. Matches index volatility to the investor's horizon and stated maximum drawdown tolerance. A 20-year horizon scores high-volatility indices better than a 5-year horizon. Indices whose max drawdown exceeds tolerance × 1.3 are penalised.
Diversification. Correlation penalty based on existing holdings. An index highly correlated to what you already hold adds less value. Existing US concentration → correlated indices penalised.
Tax wrapper fit. Binary for PEA: non-PEA-eligible indices score near zero. Assurance Vie and CTO have minor penalties only.
Factor quality. Value tilt +20, reform catalyst +10, size premium +8, growth-at-high-CAPE −25 (growth indices with CAPE >30 are penalised). Based on Fama-French and AQR factor research.

Honest Limitations
CAPE is a 10-year predictor, not a timing tool. High CAPE predicts low average returns over the subsequent decade. It says nothing about when any correction happens. The market was expensive in 1996 and doubled before correcting in 2000.
Historical returns may not represent the future. The dataset is US-centric (1928–2024). The US is the market that survived and dominated. Bootstrapping from this data embeds US survivorship bias. International diversification is partly a hedge against this.
Block size is an estimate. The optimal block size is theoretically derived but practically estimated. Results are somewhat sensitive to this parameter between 2 and 7 years. Sensitivity testing (run at block size 2 and 7, compare P10) is recommended.
